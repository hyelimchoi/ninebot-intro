# Ninebot Intro Motion Proposal

Landing page for the Ninebot 九号 intro logo motion proposal (3 themes · 7 types).

- `index.html` – the whole site (single file, no build step)
- `assets/` – hero logo, representative motion per type (`A1`–`C2`), reference clips (`ref/`), variations (`var/`)

Open `index.html` directly, or serve the folder with any static server (GitHub Pages works as-is).

Navigation: scroll / arrow keys / `Z` (next) `X` (back). Each type page steps References → Motion → Variations.
